使用 Web UI

DeepSeek Harness 是由 DeepSeek AI 开发的开源 agent harness。它采用“一切皆插件”的架构，并由 Cordis 驱动。

开发者预览

DeepSeek Harness 正在快速迭代，未来会出现破坏兼容性的变更。本页按上游公开文档整理，不承诺尚未发布的内部接口。

运行#

安装 Node.js，然后运行官方发布的 CLI：

Terminal
$ npx @deepseek-ai/dsh web
Web UI → http://127.0.0.1:3080

进程会把调用目录作为默认文件系统位置，但新的 Web UI 在添加工作区前不会选中任何工作区。

配置模型#

打开设置 → 模型，在 DeepSeek 卡片输入 API 密钥并保存。模型路由会立即可用，不需要重启服务器。

i
凭据是只写的

保存后浏览器只收到脱敏描述符。密钥存储在 $DSH_HOME/.credentials.yaml，settings 只保留凭据引用。

也可以添加 Anthropic、OpenAI 等目录提供方，或配置公司网关和自建 OpenAI 兼容端点。使用 Bedrock、Vertex、Azure 与 Codex 时，需要各自的原生认证。

选择工作区#

点击选择工作区，添加启动 dsh 时所在的项目目录，然后选中它。选中工作区前，会话输入框不可用。

运行任务#

启动一个会话并发送：

Summarize this repository and identify its main packages.

Agent 可以读取和编辑工作区文件、运行命令、委派工作并维护计划。当前权限策略要求审批时，Web UI 会先询问你。

Python SDK#

Python SDK 用于在 Web UI 之外调用相同的 Harness API。它需要 Python 3.10+；安装后的内置运行时不要求系统提供 Node.js。

Terminal
$ python -m pip install deepseek-harness-sdk
隔离运行

官方最小示例使用 danger-full-access，只能在可丢弃的 checkout 或容器内运行。

第一个 Harness 插件#

插件是一个导出 apply 函数的 TypeScript 模块。框架加载时传入 ctx，插件通过它注册能力。

TypeScript
import type { Context } from '@deepseek-ai/cordis'

export const name = 'my-plugin'

export function apply(ctx: Context) {
  // Register capabilities here.
}

插件与生命周期

事件监听、工具和定时器等通过 ctx 注册的资源会在插件卸载时自动清理。需要手动释放的连接等资源应通过 ctx.effect() 注册 disposer。

架构#

DeepSeek Harness 不是一个固定功能集合，而是由 Cordis Context 组合的一组插件。Agent loop、LLM、工具、文件访问、权限、会话持久化和 Web UI 都由可替换的插件提供。

01一切皆插件

能力通过服务、事件和配置组合，不由单体应用硬编码。

02Session 是真源

模型消息、工具结果和可恢复状态由仅追加事件日志派生。

03作用域隔离

全局贡献与单 Agent scope 保持扁平、明确的可见性边界。
