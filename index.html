使用 Web UI

用 DeepSeek Harness 启动你的第一个智能编程任务。本指南将带你完成模型配置、工作区选择和首次运行。

i
开始之前

你需要 Node.js 20+、一个 DeepSeek API Key，以及一个准备让 Agent 读取的本地项目。

安装与启动#

在终端中运行以下命令。DSH 会在当前目录启动服务，并打印 Web UI 的访问地址。

Terminal
$ npm install -g @deepseek-ai/dsh
$ dsh

配置模型#

打开右上角的 设置 → 模型，选择 DeepSeek，输入 API Key 并保存。配置会立即生效，无需重启服务。

  1. 1
    进入模型设置

    点击设置图标，在侧栏选择「模型」。

  2. 2
    添加凭证

    选择服务提供方，并粘贴你的 API Key。

  3. 3
    验证连接

    保存后状态显示为绿色，即可创建会话。

选择工作区#

点击「选择工作区」，添加你启动 dsh 时所在的项目目录。工作区决定 Agent 能够读取和修改的文件范围。

注意

选择工作区前，会话输入框保持禁用。请勿将包含敏感凭证的目录设为工作区。

权限与审批#

Harness 默认采用最小权限策略。文件写入、网络访问和高风险命令会根据你的配置触发审批，所有工具调用都会保留清晰记录。
