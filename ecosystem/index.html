安装审查

先看权限，再运行代码

身份与版本

  • 核对包名、所有者与仓库链接
  • 固定版本或提交，不追随浮动分支
  • 确认目标 DSH 版本与变更记录

能力与权限

  • 审查 tools、services、listeners 和网络请求
  • 检查凭证、工作区、Shell 与存储访问
  • 优先在隔离环境里试运行

组合与配置

  • 检查 cordis.yml、inject 与 Config Schema
  • 确认服务覆盖和依赖冲突
  • 不要复制未知配置到生产环境

卸载与回滚

  • 确认卸载会停止进程和监听器
  • 记录生成文件与配置修改
  • 备份数据并验证恢复路径
