Agent = Model + Harness

Harness 让 Agent
在真实环境中持续工作

模型是 Agent 的灵魂。Harness 让 Agent 理解环境、使用工具，并在真实世界的条件下持续完成工作。

01

Cordis 内核

Cordis 内核负责插件挂载、卸载和依赖管理；Agent 能力存在于插件中。

02

能力即插件

模型、工具、Skills、Session、沙箱、存储、循环、调度和 UI 都由插件提供，服务和事件让它们协同工作。

03

使用配置组合

开发者无需修改 DeepSeek Harness 源代码，即可在配置中选择、替换或扩展任何能力。

设计方法

一切皆插件

DeepSeek Harness 构建在 Cordis 插件系统之上。所有 Agent 能力都由插件提供；开发者可以通过配置选择、替换和扩展，而无需修改 Harness 本身。

每次运行都可追溯

模型看到的一切都记录在仅追加 Session 日志中：系统提示词、推理、工具调用与结果、子代理调度和每次上下文注入。Trajectory、恢复、Fork、搜索和回放都使用同一事件流。

多种运行模式

为不同任务重新组合 Harness

01

Standard mode

完整编码 Agent：文件编辑、Shell、文件与 Web 搜索、Skills、计划、Goals、Subagents 和 Workflows。

02

Code mode

在 Standard 能力之上，通过 Code Mode SDK 让模型在一段 TypeScript 程序中组合多步工具操作。

03

Minimal mode

只保留持久 Bash 和 str_replace_editor 的双工具编码 Agent，适合最小环境中的模型评测。

04

Creator mode

用于创建自定义 Agent Preset：包含完整 Standard 能力，以及运行时检查、插件实验和 Preset 编写指导。
