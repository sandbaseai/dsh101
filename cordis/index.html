DeepSeek Harness 的组合内核

时空可组合性

Cordis 把动态组合的两个正交问题变成运行时机制：组件移除后能否完整撤销副作用，以及组件能否声明并响应式管理依赖。

论文为 2026-08-13 预印本，仍在修订。具体结论应以最新版本为准。

时间可组合性

组件被移除时，其副作用能够完整撤销。运行时必须知道某次上下文变换的逆操作，而不是依赖插件作者在多个地方手工清理。

空间可组合性

组件能够声明自己需要的上下文，并在依赖出现、替换或消失时由运行时响应式管理，而不是假定启动顺序永远正确。

可逆副作用

每次上下文变换都携带由运行时追踪的逆变换。监听器、服务、定时器和其他注册因此可以随 Fiber 生命周期成组撤销。

响应式协效应

上下文每次变化都会根据组件的协效应规格通知并重新评估它，使依赖解析、配置协调与热模块替换共享同一个模型。

可逆 Effect+响应式 Coeffect→统一 Context 类型

为什么 Harness 需要它

Agent Harness 的模型、工具、沙箱、Session、存储和 UI 会在不同时间被选择、替换与重新组合。Cordis 让这些能力不仅能“装上去”，还能够在依赖改变时停稳、撤销并重新装配。

从理论到实现

论文把 effect context 与 coeffect context 统一成 context type，并进一步组成 component 与动态组合演算。Cordis 将其实现为带副作用追踪和依赖解析的核心库，以及支持配置协调和 HMR 的声明式 Loader。
